How to use the studio — quick tutorial
  1. New module — set title/channels/speed/bpm, press new module.
  2. Make a sound — pick a waveform + frequency under Sample generator, press ▶ preview to hear it, then + new sample to attach it (or load a full module and import its instruments/samples).
  3. Write notes — click a cell in the pattern grid, then use your keyboard: Z S X D C V G B H N J M = C…B, Q W E R T Y U = the next octave (classic tracker layout). Each key press enters the note and moves down a row.
  4. Inspect a note — the Note inspector below the grid shows the selected cell's four parts: note, instrument, volume and effect. Edit any part and it writes straight into the pattern.
  5. Fix mistakes — Ctrl/Cmd+Z undoes the last cell edit; − row / clear fix rows.
  6. Listen — play runs the song live; edits apply immediately while it plays.
  7. Save — save downloads your project as .modplayjs.json; load reopens it.
