Key decisions (file:line grounded)
----------------------------------
- volbase: IT does NOT override the load_helpers.c:303 default 0x40.
- identify_tracker called ONCE after pp tables are read (it_load.c:1382),
  needs pat_before_smp. The MPT-116 branches rewrite cmwt
  (sample_mode ? 0x100 : 0x214/0x200) — only the tracker label uses the
  rewritten value; new/old instrument choice reads ifh.cmwt directly
  (it_load.c:588).
- pp pointer tables: C reads mod->ins entries where mod->ins is STILL
  ifh.insnum (sample-mode rewrite mod->ins = mod->smp happens later,
  it_load.c:1309-1310). File layout = insnum + smpnum + patnum u32s.
- Pattern header: pat_len u16 + num_rows u16 + 2 reserved u16 = payload
  at +8 (it_load.c:1024-1029 load, :1393-1396 scan).
- load_it_sample fills mod->xxs[i] directly (it_load.c:820
  xxs = &mod->xxs[i]); instrument name vs sample name per sample_mode
  (it_load.c:880); c5spd scan over ALL instrument subs with sid == i
  (it_load.c:906-918).
- Compressed samples: left = file_len - (long)ish.sample_ptr — NO
  `start +` (C bug-compatible, it_load.c:~955); left < min_size →
  force_sample_length(left << 3); itsex decompressor errors ignored
  (void in C); ADPCM/UNS decode bits travel on raw.flags (DecodeFlag
  numeric parity with samples.ts); stereo decompressed data is planar —
  no INTERLEAVED flag (matches C convert_stereo_interleaved).
- copyAdjust stops at NUL (strncpy semantics) — IT-specific; s3m.ts
  version differs (fixed-width), intentionally untouched.
- Old IT instruments: map[j] = 0 (not 0xff) for unbound keys;
  enode[50] OOB guard: k>=25 short-circuits first (it_load.c:519-522).
- Song message: \r → \n, non-printables (except \n \t) → '.'.
- Quirks: |= ARPMEM|INSVOL; LINK_GXX → PRENV else UNISLD; new_fx →
  VIBHALF|VIBINV else ~VIBALL|ITOLDFX; sample_mode → ~VIRTUAL|~RSTCHN
  (it_load.c:1506-1524).
- OpenMPT label: "OpenMPT %d.%02x" with major = (cwt & 0x0f00) >> 8;
  " (compat.)" appended iff rsvd != "OMPT" (it_load.c:425-431).
