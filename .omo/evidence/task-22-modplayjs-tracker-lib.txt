Wiring details
--------------
- demo/vite.config.ts: workspace packages have no dist artifacts, so
  @modplayjs/* resolve straight to TypeScript sources via aliases;
  worker.format 'es' so the AudioWorklet asset loads as a module script.
- Worklet URL: AudioWorklet requires a same-origin module URL —
  demo/src/worklet-url.ts + worklet-url-impl.ts use Vite's
  `?worker&url` to emit the transpiled worklet as a hashed JS asset
  (raw `?url` would ship untransformed TS, which browsers cannot run).
  packages/out-webaudio/src/webaudio.ts: start(core, workletUrl?) calls
  audioWorklet.addModule(url) once per node.
- Restart-after-stop fix in out-webaudio: WebAudioOutput.start re-connects
  the surviving node on subsequent starts (stop() disconnects; the node
  is reused, matching the demo's load-then-play-then-stop-then-play
  cycle).
