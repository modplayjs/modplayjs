Core fix required by T19 (found while rendering to module end)
--------------------------------------------------------------
Core.playBuffer had NO end-of-replay signal: it looped frames forever
because checkEndOfModule increments _p.loop_count at the scan end row
and the module restarts (nothing returned -1). Ported xmp_play_buffer
(player.c:2178-2233) verbatim: loop parameter (default 1); after each
frame the check `ret < 0 || (loop > 0 && loop_count >= loop)` runs
BEFORE copying the frame — the crossing frame is discarded; when
nothing has been filled the call returns -1 (end of replay), otherwise
the buffer is short and the NEXT call returns -1. Previously the check
ran after adding the frame to the output, which made every call return
a full buffer and never signal the end.
